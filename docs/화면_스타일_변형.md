# 화면 스타일 변형(멀티 UI) — 구조·전환·모션·채점

AOI 매칭 검증 앱은 **5가지 완성 화면 스타일(변형)** 을 제공한다. 색만 다른 게 아니라
레이아웃·타이포·밀도·컴포넌트 형태·모션까지 변형마다 다르되, **프로그램의 동작·흐름은
어떤 스타일에서도 동일**하다(스캔→Setup→선별→매칭→검토→결과).

## 다섯 변형

| key | 라벨 | 성격 | 구조 시그니처 |
|---|---|---|---|
| `instrument` | 계측기 | 어두운 검사 부스, 앰버 단일광(현재 개선) | 썸네일 레티클 틱 · 카드 행 · primary 글로우 |
| `cleanroom` | 명실 | 밝은 클린룸, 코발트 | 고정 컬럼 헤더 데이터테이블 · 지브라 띠 · 하이라인 밀집 |
| `datum` | 도면 | 벨럼 제도 시트 | 청사진 블루 · 샤프 스탬프 칩 · 모노 수치 · 가시 눈금 |
| `clarity` | 큰 글씨 | 접근성 대형 | 16px/800 · 거리 수치 대형 헤드라인 · 48px 컨트롤 · 800px 컴팩트 |
| `patina` | 청동 | 딥 버디그리스 + 구리 | verdigris 썸네일 프레임 · 둥근 브론즈 카드 · 완전 원형 칩 |

## 아키텍처 (단일 출처)

- **`ui/theme.py`** — `Variant(key, label, colors, profile, scrim, shadow)` 와 `VARIANTS` 사전.
  - `colors`: 17색 키(bg/panel/…/accent/pass/danger/focus/**thumb_frame**).
  - `Profile`(frozen dataclass): **구조 파라미터** — 서체 크기·굵기·자간, radius 계열, 밀도
    (margin/pad/row_gap), control_h, chip_style(pill/text), row_style(card/hairline),
    card_shadow, primary_glow, chip/toggle 크기, thumb_default_px, focus_ring_px,
    motion_scale, 그리고 구조 플래그 `list_header`·`thumb_reticle`·`zebra_rows`·
    `score_hero`·`compact_narrow_px`.
  - `set_variant(name)`: 모듈 전역(BG/PANEL/…/PROFILE/SCRIM/SHADOW)을 일괄 재할당하고
    `TOKENS` 를 in-place 갱신(보유 참조 유지). `theme.X` 참조 코드는 무수정.
- **`ui/style.qss`** — 단일 `$token` 템플릿. `render_qss(TOKENS)` 가 치환 → `apply_to_app`.
  색뿐 아니라 서체 px·radius·패딩·칩·행·눈금(`score_rule`)·지브라(`zebra_bg`)까지 토큰.
- 인라인 f-string 색은 위젯 생성 시점에 박히므로, **전환 = 전역 재할당 + QSS 재렌더 +
  페이지 5개 재구축**. 세션 시작 전(셋업)에서만 허용 → 상태 손실 없음.

**PROFILE 분기 예산**: 구조가 QSS 로 표현 안 되는 곳(레티클 페인트·컬럼 헤더·지브라·판독
대형·컴팩트 등)만 코드에서 `theme.PROFILE.*` 를 읽는다. 색/치수 대부분은 QSS 토큰으로
해결(분기 최소화).

## 전환 (셋업 상단 스위처)

- 셋업 첫 화면 상단 `‘화면 스타일’` 스위처(변형 칩) — 누르면 그 디자인으로 **즉시 전환**.
  선택 상태는 채운 accent 칩으로 강조(현재 스타일 한눈에).
- `main_window._on_variant_selected`: `PHASE_NONE`(셋업)에서만, prefs 저장 → `set_variant`
  → `apply_to_app` → `_rebuild_pages`(페이지 5개 파괴·재생성) → 이전 화면 스냅샷 크로스페이드.
- 선택은 `prefs.ui_variant` 로 영속(다음 실행 유지). 시작 시 `main.py` 가 적용.

## 모션 (`ui/motion.py`)

- 이징 기본 **OutQuart**(ease-out). `enabled()` 는 offscreen(테스트/캡처)·앱 '모션 줄이기'·
  **OS 동작 줄이기**(Windows SPI) 면 False → 모든 헬퍼 즉시 스냅(결정론).
- 화면 전환: `transition_in` — 들어오는 화면 스냅샷이 방향성(앞/뒤) 슬라이드+페이드 진입.
- 로딩 오버레이: 등장 160ms·퇴장 120ms + **최소 표시 350ms 래치**(깜빡임 방지).
- 로딩바: 결정형 OutQuart 트윈 / busy 등속 혜성 스윕 / 스피너 숨쉬는 호 — 모두
  `motion_scale` 로 스케일. **CLAUDE.md 로딩 계약**(set_progress 시그니처·의미) 유지.
- 프레스 피드백: 글로우 변형은 blur 트윈, 그 외는 opacity 딥. 행 상태 펄스. 스크롤은
  프로그램적 이동만 부드럽게(휠은 네이티브).

## 품질 채점 루프

성격이 다른 채점자 5인(접근성·모션 디렉터·현장 오퍼레이터·타이포 순수주의자·안티슬롭
아트디렉터)이 24개 항목(10점)으로 채점. **어떤 채점자든 어떤 항목 ≤9.3 → 개선 후 재채점.**
1라운드 130건 → 2라운드 7건 → 3라운드 0건 수렴(전 항목 9.4+).

## 불변식 (깨지 말 것)

- 전 변형 **전 기능 색상쌍 WCAG AA 여유(≥5.0, 포커스 ≥3)** — `dev/tests/test_variants.py`.
- 800×600 대응, 가로 스크롤 0(뷰포트 기준 재클램프) — `test_match_review_clamp.py`.
- instrument 프로필 = 현행 리터럴 고정(기존 클램프·a2 테스트 무수정 통과).
- QScrollArea 뷰포트 배경은 **objectName 스코프**로만(맨 선언 금지 — 자식 :checked 채움을
  덮어써 스위처 '빈 박스' 버그) — `test_setup_switcher.py`.
- 새 변형/구조 플래그를 더할 때 대응 테스트를 추가한다.
