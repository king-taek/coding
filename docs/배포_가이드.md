# 배포 가이드 — 전부 담은 폴더를 zip 으로

> 배포 방식은 **하나**다. 파이썬·라이브러리·백본 IR·앱을 전부 담은 `dist\AOI_Verify\` 를
> zip 으로 전달하고, 받는 사람은 **압축을 풀고 `run_aoi.bat`** 을 더블클릭한다.
> 사용자 PC 는 아무것도 내려받지 않으며 파이썬도 필요 없다. exe 런처·exe-lite·온라인
> 다운로드 방식은 없앴다(회사 보안이 서명 없는 exe 를 지우고, 첫 실행 다운로드는
> 사내망에서 막힐 수 있다). 업데이트 동작은 `docs/업데이트_동작.md`.

## 만드는 사람 (배포할 때마다)

필요: Windows + 파이썬 3.9+ + 인터넷 + 디스크 여유 10 GB 이상. 저장소 루트에서:

```powershell
python scripts\build.py portable      # dist\AOI_Verify\ 생성, 끝에 자동 검증
python scripts\make_release_zip.py    # 검증 통과 시 dist\AOI_Verify_<날짜>_<커밋>.zip
```

- 빌드는 CPython 런타임을 받고, `requirements.txt` 를 **빌드 PC 에서** 설치하고, 커밋된
  백본 IR(`runtime/ir`)을 복사한다. 커밋 전이면 그 자리에서 변환한다.
- 커밋·푸시를 끝낸 뒤 빌드한다(`app/VERSION` 에 HEAD 커밋이 박혀 자동 업데이트 기준이 된다).
- 검증이 실패하면 zip 을 만들지 않는다. 실패 항목과 다음에 할 일이 출력된다.
- 중간에 멈추면 같은 명령을 다시 실행한다(`python\` 은 재사용된다).

## 받는 사람

1. zip 을 짧은 경로(예: `C:\AOI_Verify`)에 푼다. `Program Files` 안은 피한다.
2. `run_aoi.bat` 을 더블클릭한다. 켜진 뒤 같은 폴더에 `AOI 레시피 검증` 바로가기가 생긴다.
3. 안 켜지면 `run_aoi_debug.bat` 의 오류 화면을 캡처해 전달한다.

## 폴더 구조

```
AOI_Verify\
  python\            번들 CPython + 라이브러리 (거의 불변)
  app\               앱 소스·리소스·IR (자동 업데이트가 바꾸는 전부)
  결과\               엑셀 출력 (업데이트에 안 쓸림)
  run_aoi.bat        실행 + 업데이트 교체
  run_aoi_debug.bat  오류 확인용
  설치방법.txt         zip 에 자동 포함
```

새 패키지가 필요한 변경(`requirements.txt`)을 배포하려면 zip 을 다시 만들어 전달한다.
앱이 설치를 시도하지만 인터넷이 막히면 업데이트가 적용되지 않기 때문이다.
