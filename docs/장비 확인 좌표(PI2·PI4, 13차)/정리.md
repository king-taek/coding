```
x_index = floor(86798  / 37248.2) = 2   →  col = 2 − col_origin(2) = 0     장비 0  ✓
y_index = floor(148549 / 44905.5) = 3   →  row = row_total(6) − 3   = 3     장비 3  ✓
```

→ 폴백이 **장비 기준으로 틀리다**는 것이 처음 확인됐다(그전까지는 "우리 유도값과 다르다" 까지였다).

## 2. PI2 `MTW-PIDS7` / `00RWQ258XYD1` (AOI-22) — 대체 웨이퍼

원래 요청한 `00RWP232XYF1` 은 결함이 0건이라 **같은 로트의 다른 웨이퍼**로 대체됐다.

**대체가 타당한 근거**

| | 값 | 등급 |
|---|---|---|
| `00RWP232XYF1` 중심 | `(204996.8, 179680.5)` | 유도 |
| `00RWQ258XYD1` 중심 | `(205028.3, 179693.9)` | 유도 |
| 차이 | **X 31.6 / Y 13.4 µm** — 경계 여유 15,355 µm 의 1/480 | 유도 |
| 두 웨이퍼의 `(col_origin, row_total)` | 둘 다 `(2, 6)` | 유도 |

> R2(표본 단위) 적용: `Wafer2Table` 은 **웨이퍼마다 측정**되는 값이므로
> 원칙적으로 다른 웨이퍼로 대체하면 안 된다(E10 의 교훈). 여기서는
> **대체 웨이퍼 자신의 `Wafer2Table.ini` 를 함께 받았기 때문에** 문제가 없다 —
> 그 웨이퍼의 결론은 그 웨이퍼의 파일에서 나온다. 원래 웨이퍼와의 31 µm 차이는
> '대체해도 되는가' 가 아니라 '로트 안에서 안정적인가' 를 말해 주는 별개 정보다.

**전체 INI 수령 — 결함 35건**

```
격자 불변식  X: Col == floor(X/pitch_x)          35건 전수 통과 ✓
            Y: floor(Y/pitch_y) − Row = {0}     상수 ✓
row 분포 [0,1,2,3,4]   col 분포 [0,1,2,3,4,5,6]   ← 둘 다 0 에 닿음
```

`row` 가 0 에 닿는 것은 방증이다 — 폴백(7)이면 row 가 1~5 가 되어
**맨 윗줄에 결함이 하나도 없는** 모양이 된다.
단, 이건 `유도` 등급이지 `관측` 이 아니다(결함 분포가 우연히 그럴 수도 있다).

**장비 확인 대기 중인 2건** (아직 `관측` 등급 값 없음)

## 3. PI4 `DYD-PIDS3` / `29265187EWF2` (AOI-17) — ★ die 내부 x·y 의 첫 장비 대조

사용자 확인: "요청한 DEFECT의 col, row, x, y … 첫번째 것: 예측값과 동일합니다. 두번째 것: 예측값과 동일합니다."

| 사진 | 절대 X | 절대 Y | col | row | die내부 x | die내부 y | 등급 |
|---|---:|---:|---:|---:|---:|---:|---|
| `241598.321074.c.-261182989.1.jpeg` | 241,598.6 | 321,072.3 | **4** | **0** | **18,112** | **6,734** | 관측 |
| `146810.150100.c.-581351445.1.jpeg` | 146,812.1 | 150,100.3 | **1** | **4** | **35,069** | **15,384** | 관측 |

**의미** — 지금까지 die 내부 x·y 는 *소스끼리* 비교만 했다(파일명 ↔ INI 계산).
두 소스가 같은 규칙으로 같이 틀릴 수 있었다. 이 2건이 **장비 화면과의 첫 대조**다.

첫 건은 `row 0` 이라 그 자체로 `row_total ≥ 7` 을 증명한다(6이면 row 가 −1).

> ⚠ 이 2건이 **증명하지 않는 것**: 버림 vs 반올림.
> 네 값의 소수부가 전부 0.5 미만이라 두 방식이 **같은 숫자**를 낸다.
>
> ```
> 18112.4484 → 버림 18112 / 반올림 18112   (구분 못 함)
>  6734.4667 → 버림  6734 / 반올림  6734   (구분 못 함)
> 35069.0103 → 버림 35069 / 반올림 35069   (구분 못 함)
> 15384.1267 → 버림 15384 / 반올림 15384   (구분 못 함)
> ```
>
> 버림을 지지하는 관측은 여전히 골든 사례 1건(`43180.809 → 43180`)뿐이다.
> 소수부 ≥ 0.5 인 결함 1건이 있으면 닫힌다.

## 5. 이번 수령으로 바뀐 것 / 안 바뀐 것

**바뀐 것**

- 장비 정답 **13 → 16건**
- `row_total=6` 쪽 장비 근거: **0 → 1건** (그전까지 6은 `Wafer2Table` 역산뿐이었다)
- die 내부 x·y 장비 대조: **0 → 2건**
- 폴백의 오류: "우리 유도값과 다르다" → **"장비 기준으로 틀리다"**

**안 바뀐 것** (R5 — 이걸 안 적으면 다음 세션이 닫힌 줄 안다)

- 경계 근접(여유 <33 %) 자재: **여전히 0건**
- `EBR≠0` · 300 mm 아닌 웨이퍼 · KLA notch UP/mirrored: **여전히 0건**
- `Diameter` vs `MeasuredDiameter` 구분: **여전히 안 됨**
- 버림 vs 반올림: 골든 **1건**뿐 (이번 2건은 구분 못 함)
- `Wafer2Table.ini` 이 없는 스캔이 존재하는지: **미확인**
